# LearnPWA - Progressive Web App Learning Application

A modern, fast, modular, and fully offline-capable learning PWA built with vanilla HTML, CSS, and JavaScript.

## Features
- **Modular Architecture:** Clean separation of UI views, routing, data models, and storage handlers.
- **Offline First:** Fully caches assets and JSON datasets using a Service Worker.
- **Dynamic Content:** Loads subjects, lessons, quizzes, and notes straight from JSON files.
- **GitHub Pages Ready:** Can be deployed instantly with zero build steps required.

## Running Locally
1. Clone the repository.
2. Serve the root folder using any local development server (e.g., Live Server extension in VS Code).
3. Open in your browser.
